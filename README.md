# AI Andorra – Presentasjonsside

Enkel presentasjonsside for AI Andorra, NordicIQs egen AI-plattform.

Teknologier: Vite, React, TypeScript.

## Kjøre lokalt

```bash
npm install
```

Start utviklingsserver (åpne http://localhost:5173):

```bash
npm run dev
```

Bygg for produksjon (output i `dist/`):

```bash
npm run build
```
